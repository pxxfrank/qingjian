# 轻笺 · Windows 便笺

轻量级 Windows 便笺应用：**Markdown 所见即所得**，输入语法即时渲染，支持**贴边启动器（收进边缘小球）**、悬浮置顶、暗夜模式、自由调整大小、便笺列表。

## 功能

| 功能 | 说明 |
|---|---|
| ✍️ Markdown 所见即所得 | 输入 `# `→标题、`- `/`* `→无序列表、`1. `→有序列表、`[] `→复选框、`> `→引用；`**粗**`、`*斜*`、`__下划线__`、`~~删除~~`、`` `代码` `` 即时渲染 |
| ✅ 复选框 | 输入 `[] 内容` 即变成复选框，点击切换勾选状态 |
| 📌 悬浮置顶 | 标题栏图钉按钮切换 always-on-top |
| 📎 贴边启动器 | 屏幕边缘**常驻半个小球**；点标题栏 **⇲** 把窗口**缩进小球**；鼠标移上小球 → 展开成**扁长横条**（列表 + 被收起的便笺 + 新建＋）；拖动能上下移动、左右换边 |
| 🌙 暗夜模式 | 列表页按钮三态切换：跟随系统 / 亮色 / 暗色，多窗口同步 |
| 🪟 自由调整 | 无边框窗口，拖边缘随意调整大小；位置/大小自动记忆 |
| 📋 便笺列表 | 新建 / 搜索 / 打开 / 删除，显示标题、预览、更新时间 |
| 🔒 自动保存 | 输入即保存（400ms 防抖），数据存于 `%APPDATA%\轻笺\notes\` |

## 启动

```bash
npm install
npm start
```

## 贴边启动器

- 便笺/列表**默认都是普通窗口**，不会自动隐藏。点标题栏的 **⇲** 才把它**收起到贴边**：窗口朝小球所在点带**缩小动画**缩进屏幕边缘的**半个小球**。
- 小球**常驻**屏幕边缘（除非退出整个程序）。只有**被收起的窗口**才在小球里（默认空）。
- **鼠标移到小球 → 展开成扁长横条**：`☰ 列表` + **每个被收起的便笺**（颜色圆点，悬停显示标题）+ `＋ 新建`；**鼠标移开 → 收回小球**。点图标即打开/取回对应窗口。
- 小球常态**半透明（70%）**，鼠标移上变**不透明（100%）**。
- **拖动小球/横条**：上下移动位置；把光标拖到屏幕左半边 / 右半边即可**切换贴左 / 贴右**。位置与贴边侧会被记住（`settings.json` 的 `launcherY` / `launcher`）。

## Markdown 语法速查

| 输入 | 效果 |
|---|---|
| `# 标题` | 一级标题（`##` `###` … `######` 同理） |
| `- 项目` / `* 项目` | 无序列表，回车自动延续 |
| `1. 项目` | 有序列表，编号自动递增 |
| `[] 待办` / `[x] 完成` | 复选框 |
| `> 引用` | 引用块 |
| `**加粗**` | 加粗 |
| `*斜体*` | 斜体 |
| `__下划线__` | 下划线 |
| `~~删除线~~` | 删除线 |
| `` `代码` `` | 行内代码 |

列表内按回车自动延续并保留前缀；空行回车退出列表；空列表项开头按 Backspace 退出列表。
工具栏按钮与 `Ctrl+B / Ctrl+I / Ctrl+U / Ctrl+Shift+X` 快捷插入对应格式。

## 技术栈

Electron（主进程/预加载）+ Vue 3 + Vite 打包的渲染层。`contenteditable` 渐进式 Markdown 转换引擎，`contextIsolation` 安全隔离，每张便笺独立 JSON 文件存储；贴边启动器由 `launcher.js` + `launcher-geometry.js`（纯几何，可单测）实现。

## 打包

```bash
npm run dist            # 构建 + 数字签名 + 打包（推荐）
npm run dist:unsigned   # 只打包，不签名
npm run cert:dev        # 只生成自签名开发证书
```

产物：
- 安装包 `dist/轻笺-Setup-<version>.exe`（NSIS，可自选安装目录、创建桌面/开始菜单快捷方式、中文安装界面）
- 免安装版 `dist/win-unpacked/轻笺.exe`（双击即用）

> 体积：安装后约 **276 MB**（安装包约 80 MB）。已做优化——只保留中文/英文两套界面语言、最高压缩、剔除仅 WebGPU 用的着色器编译器。**其中 `轻笺.exe` 约 215 MB 是 Electron/Chromium 运行时本身**，属于这类应用的体积下限；若要 10 MB 级体积需改用 Tauri / 系统 WebView2。

### 代码签名

打包会用 signtool 对 `轻笺.exe`、卸载器和安装包签名，并打 DigiCert 的 RFC3161 时间戳。

- **默认**：`npm run dist` 使用 `certs/qingjian-sign.pfx`；没有则自动生成一张**自签名**证书（也可 `npm run cert:dev` 手动生成）。自签名证书能产生**合法签名**，但根证书不在系统信任列表里，别人机器上 SmartScreen 仍会提示"未知发布者"。
- **正式发布**：换成 CA（DigiCert / Sectigo 等）颁发的代码签名证书即可，**代码无需改动**：
  - 方式一：把 `.pfx` 放到 `certs/qingjian-sign.pfx`；
  - 方式二（CI 常用）：外部设置环境变量 `CSC_LINK`（.pfx 路径）与 `CSC_KEY_PASSWORD`，再 `npm run dist`。
- 证书与口令放在 `certs/`（已在 `.gitignore`，不会被提交）。

**安装包只含程序代码，不含任何便笺数据。** 所有数据都放在用户目录 `%APPDATA%\轻笺\`（`notes/` 便笺、`trash/` 回收站、`attachments/` 图片附件、`settings.json` 设置）。因此：每台机器 / 每个 Windows 用户**首次运行都是空数据**，数据始终保留在本地，不会随安装包分发；卸载时也默认**不删除**这些数据（`deleteAppDataOnUninstall: false`）。

electron-builder 已配置完成；Electron 二进制与打包工具均走 npmmirror 镜像（见 `.npmrc`）。
